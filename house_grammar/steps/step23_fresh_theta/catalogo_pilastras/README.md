# Catálogo de pilastras y columnas

35 GLB: 25 variantes únicas, cinco conjuntos y cinco ejemplos de anclaje.
Empieza por los archivos `00_conjunto_*/building.glb`. No hay combinaciones exhaustivas.

Los GLB individuales muestran solo la pieza. Sus requests incluyen un edificio de anclaje.
En cada conjunto el orden de izquierda a derecha coincide con la tabla siguiente.

| Estilo | Variantes de izquierda a derecha |
|---|---|
| republicano | smooth_moulded, recessed_panel, restrained_fluted, rusticated, portico_column |
| barroco | scroll_pilaster, leaf_pilaster, salomonic, estipite, composite_column |
| clasico | tuscan, doric, ionic, corinthian, panel_pilaster |
| madera | chamfered_post, turned_post, octagonal_post, joinery_pilaster, saddle_post |
| moderno | plain_prism, plain_cylinder, oval_column, grooved_pilaster, tapered_column |
